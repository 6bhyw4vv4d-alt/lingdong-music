# 社保生命周期公众号图片系列

这个资料包按生命周期顺序介绍中国大陆社保：

1. 出生、上学：居民医保
2. 毕业入职：职工五险
3. 每月工资条：缴费基数和地区差异
4. 生病看医生：医保报销逻辑
5. 生育阶段：生育医疗费和生育津贴
6. 工作受伤：工伤保险
7. 失业阶段：失业保险
8. 换工作、换城市：转移接续和异地就医
9. 自由职业：灵活就业社保
10. 退休：养老保险兑现长期积累
11. 失能照护：长期护理保险
12. 地区差异：本地化清单
13. 避坑五问：最后总结

## 文件说明

- `draw-images.py`：最终 PNG 图片源稿和导出脚本，包含最新校对后的文案。
- `images/`：最终 PNG 图片，1080 x 1440，适合公众号图文逐张插入。
- `output/contact-sheet.png`：总览缩略图。
- `output/社保生命周期公众号图片.zip`：公众号图片压缩包。
- `sources.md`：参考口径和核对入口。

## 重新导出

如需重新生成图片，运行：

```bash
python3 draw-images.py
```

本稿是原创轻漫画信息图，采用通俗、夸张、分镜式表达，不复刻任何具体漫画书或作者画风。每张图围绕“是什么、怎么用、注意事项”，并尽量用生活例子解释偏条文的内容。

## 口径说明

- 为适合官方宣传使用，图片不写各地具体金额、比例和办理时限。
- 涉及地区差异的内容统一提示以参保地最新官方口径为准。
- 退休政策已按 2025 年起渐进式延迟退休、2030 年起最低缴费年限逐步提高的口径更新。
- 长期护理保险已按 2026 年《加快建立长期护理保险制度实施方案》纳入生命周期。
