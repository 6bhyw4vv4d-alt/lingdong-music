# 灵动音乐 v0.2.0-beta.1

这是首个可安装的 macOS 内测版本。

## 安装

1. 下载 `灵动音乐-v0.2.0-beta.1-macos-universal.dmg`。
2. 打开 DMG，将 `灵动音乐.app` 拖入 Applications。
3. 在“应用程序”中右键 `灵动音乐.app`，选择“打开”。
4. 首次使用时，允许灵动音乐控制 Music.app。

## 主要功能

- 顶部置顶、可拖动的同步歌词胶囊。
- 自动读取 Music.app 当前歌曲并从 LRCLIB 匹配歌词。
- 支持人工匹配、粘贴 LRC、歌词偏移和显示样式。
- 菜单栏支持显示/隐藏歌词、打开权限设置、关于和退出。
- 设置与人工歌词独立保存在 `~/Library/Application Support/灵动音乐/`。

## 已知限制

- 当前版本采用临时签名且未经过 Apple 公证，因此首次启动必须右键打开。
- 仅支持 Music.app / Apple Music。
- Intel Mac 架构已包含在安装包中，但尚未完成实机验证。
- 暂不支持自动更新。

下载后可以使用同名 `.sha256` 文件验证安装包完整性。
