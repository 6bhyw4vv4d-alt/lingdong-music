# 灵动音乐 v0.2.0-beta.2

修复首个内测版无法直接关闭和重复启动后显示多个歌词胶囊的问题。

## 安装

1. 下载 `Lingdong-Music-v0.2.0-beta.2-macos-universal.dmg`。
2. 打开 DMG，将 `灵动音乐.app` 拖入 Applications，替换旧版本。
3. 在“应用程序”中右键 `灵动音乐.app`，选择“打开”。

## 修复

- 胶囊右侧新增“×”退出按钮。
- 菜单栏仍可使用“退出灵动音乐”完整退出。
- 再次启动时自动唤起已有实例，不再创建重复歌词窗口。

## 已知限制

- 当前版本采用临时签名且未经过 Apple 公证，因此首次启动必须右键打开。
- 仅支持 Music.app / Apple Music。
- Intel Mac 架构已包含在安装包中，但尚未完成实机验证。
- 暂不支持自动更新。
