灵动音乐 v0.2.0-beta.2 内测版

安装
1. 将“灵动音乐.app”拖入旁边的 Applications 文件夹。
2. 打开“应用程序”，右键“灵动音乐”，选择“打开”。
3. 在首次安全提示中再次选择“打开”。
4. 播放 Music.app 中的歌曲，并允许灵动音乐控制 Music.app。

使用
- 顶部歌词胶囊可以直接拖动。
- 点击胶囊中的“修正”，可重新匹配、粘贴 LRC，并用“早 / 准 / 晚”调整歌词快慢。
- 外文歌词如果带有相同时间戳的中文行，会在原歌词下面自动显示中文。
- 打开修正面板后可用快捷键调整，每次 0.5 秒并自动保存：⌥[ 提前、⌥0 恢复同步、⌥] 延后。
- 点击胶囊右侧的“×”可以直接退出。
- 点击菜单栏中的音符图标，可以隐藏/显示歌词、打开权限设置或退出。

数据与隐私
- 设置和人工歌词保存在：
  ~/Library/Application Support/灵动音乐/
- 灵动音乐只向 LRCLIB 发送匹配歌词所需的歌曲名、歌手、专辑和时长。
- 灵动音乐不会读取或保存 Apple ID、密码或登录凭据。

卸载
1. 从“应用程序”删除“灵动音乐.app”。
2. 如需一并删除设置和人工歌词，再删除：
   ~/Library/Application Support/灵动音乐/

已知限制
- 这是未使用 Apple Developer ID 签名和公证的内测版，首次启动必须右键打开。
- 当前只支持 Music.app / Apple Music。
- Intel Mac 架构已包含在安装包中，但尚未完成实机验证。
- 再次启动灵动音乐时会自动使用已有实例，不会重复显示多个歌词胶囊。
