# 音悦台 PRD

## 1. 文档信息

- 产品名称：音悦台
- 文档类型：产品需求文档 PRD
- 当前版本：v0.1
- 编写日期：2026-05-31
- 产品阶段：个人原型 MVP
- 目标平台：macOS

## 2. 产品概述

音悦台是一款面向个人使用的 macOS 桌面歌词工具。产品在用户播放 Apple Music 时，于屏幕顶部显示一个类似“灵动岛”的悬浮歌词胶囊，实时展示当前歌曲信息和同步歌词，让用户在写作、办公、浏览网页或使用其他应用时，也能自然地看到当前播放歌词。

第一版重点验证三件事：

1. 能稳定读取 Apple Music 当前播放歌曲、播放状态和进度。
2. 能从 LRCLIB 自动匹配同步歌词，并随播放进度切换当前句。
3. 能以一个轻量、置顶、可拖动、不打扰的桌面胶囊形式展示歌词。

## 3. 背景与机会

macOS 自带 Music.app 在桌面场景下缺少轻量歌词展示能力。用户在听歌时经常处于多任务状态，不希望频繁切回播放器查看歌词，也不希望打开一个体积较大的完整播放器窗口。

音悦台的机会在于提供一个“只做一件事”的桌面歌词体验：常驻、轻巧、好看、可控。它不替代 Apple Music，也不读取 Apple Music 官方歌词，而是围绕桌面悬浮歌词体验做最小可用产品。

## 4. 目标用户

### 4.1 核心用户

- 使用 macOS 和 Apple Music 听歌的个人用户。
- 经常在工作、学习、写代码、写作时听歌。
- 希望歌词始终可见，但不想被大型播放器窗口打断。

### 4.2 早期用户

- 项目 owner 自己。
- 愿意接受脚本启动、手动授权和手动修正歌词匹配的用户。

## 5. 用户问题

1. 听歌时想看歌词，但切回 Music.app 太打断。
2. 普通桌面歌词窗口容易占位置、样式突兀、不够精致。
3. 自动歌词匹配可能选错版本，需要一个简单的人工修正方式。
4. Music.app 未运行、未播放、网络失败或权限不足时，工具应清楚提示，而不是静默失败。

## 6. 产品目标

### 6.1 MVP 目标

- 启动后显示一个顶部居中的悬浮歌词胶囊。
- 自动读取 Apple Music 当前播放信息。
- 自动查询 LRCLIB 并优先匹配同步歌词。
- 根据播放进度展示当前歌词句。
- 支持暂停、继续、切歌等基础播放状态变化。
- 支持匹配失败后的人工补充和本地保存。

### 6.2 非目标

- 第一版不做完整播放器。
- 第一版不读取 Apple Music 官方歌词。
- 第一版不做账号系统、云同步、订阅付费。
- 第一版不做 App Store 打包。
- 第一版不支持 Spotify、网易云音乐等其他播放器。
- 第一版不做复杂偏好设置和插件系统。

## 7. 成功指标

### 7.1 可用性指标

- 启动成功率：本机可稳定启动并显示窗口。
- 当前歌曲读取成功率：Music.app 播放中时能读取歌曲名、歌手、专辑、时长和进度。
- 同步歌词匹配成功率：常见歌曲能自动匹配到同步歌词。
- 切歌响应：切歌后能在短时间内更新歌曲信息并重新匹配歌词。

### 7.2 体验指标

- 悬浮窗口不遮挡主要工作区域。
- 歌词过长时不撑破窗口。
- 异常状态提示明确，用户知道下一步该做什么。
- 手动修正一次后，同一首歌再次播放能直接命中保存结果。

## 8. 核心使用场景

### 场景 1：正常播放

用户打开 Music.app 播放歌曲，再从终端启动音悦台。音悦台在屏幕顶部显示当前歌曲和当前歌词，歌词随播放进度自动切换。

### 场景 2：切换歌曲

用户在 Music.app 中切到下一首歌。音悦台检测到歌曲变化，更新歌曲信息，重新查询歌词，并显示新歌歌词。

### 场景 3：暂停与继续

用户暂停播放。音悦台保留当前歌词句，并显示暂停状态。用户继续播放后，歌词恢复同步。

### 场景 4：未找到歌词

LRCLIB 没有匹配到同步歌词。音悦台继续展示歌曲信息，并提示“未找到同步歌词”，用户可以打开人工补充面板进行修正。

### 场景 5：手动修正匹配

用户修改歌名、歌手、专辑或时长后重新搜索，选择正确候选歌词并保存。之后再次播放同一首歌时，音悦台优先使用本地保存的映射。

### 场景 6：Music.app 不可用

Music.app 未运行、未播放或系统权限不足时，音悦台不退出，显示对应等待或授权提示。

## 10. 用户流程

### 10.1 首次启动流程

1. 用户从终端启动音悦台。
2. 系统请求允许脚本控制 Music.app。
3. 用户授权后，音悦台读取 Music.app 状态。
4. 如果正在播放，展示歌曲信息并查询歌词。
5. 如果未播放，展示等待状态。

### 10.2 自动歌词流程

1. 读取当前歌曲元数据。
2. 检查本地人工映射。
3. 如果命中本地映射，直接加载指定歌词。
4. 如果未命中，调用 LRCLIB 查询。
5. 对候选结果排序。
6. 选择最佳同步歌词。
7. 解析 LRC 并随进度展示当前句。

### 10.3 手动修正流程

1. 用户打开人工补充面板。
2. 修改歌曲信息或输入 LRCLIB ID / LRC 文本。
3. 点击重新搜索或保存。
4. 音悦台验证结果可用。
5. 保存到本地映射文件。
6. 返回歌词胶囊显示。

## 11. 页面与状态设计

### 11.1 主胶囊

- 位置：默认屏幕顶部居中。
- 尺寸：宽度适中，避免遮挡菜单栏和主要内容。
- 内容结构：
  - 上方：歌曲名 - 歌手。
  - 下方：当前歌词。
- 交互：
  - 拖动移动位置。
  - 点击或辅助按钮进入人工补充面板。

### 11.2 人工补充面板

- 入口：主胶囊在未找到歌词或用户主动操作时打开。
- 字段：
  - 歌名
  - 歌手
  - 专辑
  - 时长
  - LRCLIB ID
  - LRC 文本
- 操作：
  - 重新搜索
  - 保存
  - 取消

### 11.3 状态文案

| 状态 | 展示文案 |
| --- | --- |
| Music 未运行 | 等待 Music.app |
| 未播放 | 暂无播放内容 |
| 播放中但查询中 | 正在匹配歌词 |
| 找到歌词 | 展示当前歌词句 |
| 暂停 | 保留当前歌词，并标识暂停 |
| 未找到同步歌词 | 未找到同步歌词 |
| 网络失败 | 歌词服务暂不可用 |
| 权限失败 | 需要允许控制 Music.app |

## 12. 数据设计

### 12.1 overrides.json 示例

```json
{
  "version": 1,
  "tracks": {
    "music-track-id:123456": {
      "title": "Song Title",
      "artist": "Artist Name",
      "album": "Album Name",
      "duration": 240,
      "source": "lrclib",
      "lrclibId": 12345,
      "updatedAt": "2026-05-31T00:00:00Z"
    },
    "normalized:artist-name|song-title|240": {
      "title": "Song Title",
      "artist": "Artist Name",
      "duration": 240,
      "source": "manual-lrc",
      "lrcText": "[00:01.00] lyric line",
      "updatedAt": "2026-05-31T00:00:00Z"
    }
  }
}
```

### 12.2 本地存储原则

- 只保存歌词匹配所需的本地映射。
- 不保存 Apple ID、密码、token 或登录凭据。
- 不上传本地音乐库信息，除查询 LRCLIB 所需字段外不发送额外数据。

## 13. 技术约束

- 第一版使用 JXA 和 macOS 自带能力实现。
- 第一版不引入 npm、pnpm、yarn 等包管理依赖。
- UI 使用 AppKit Objective-C bridge 创建窗口和控件。
- 播放状态通过 AppleScript/JXA 读取 Music.app。
- 歌词来源使用 LRCLIB。
- 本地映射使用 JSON 文件。

## 14. 验收标准

1. Music.app 未运行时，音悦台显示等待状态，不崩溃。
2. Music.app 播放中时，音悦台能展示当前歌曲信息。
3. 自动匹配成功时，歌词能随播放进度切换。
4. 切歌后，音悦台能重新匹配并显示新歌歌词。
5. 暂停时歌词停留在当前句，继续后恢复更新。
6. 自动匹配失败时，用户能进入人工补充面板。
7. 用户保存人工映射后，同一首歌再次播放能直接使用保存结果。
8. 网络失败时，窗口保留并显示错误状态。
9. 权限失败时，提示用户需要允许脚本控制 Music.app。
10. 歌词过长时，窗口保持稳定，不被撑破。

## 16. 风险与待确认

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| JXA + AppKit 桥接稳定性有限 | UI 实现可能遇到系统版本差异 | 优先实现最小 UI，复杂交互后置 |
| Music.app 自动化权限被拒绝 | 无法读取播放信息 | 提供明确授权提示 |
| LRCLIB 匹配不准 | 歌词错配影响体验 | 增加排序规则和人工映射 |
| 网络不可用 | 无法查询新歌词 | 保留本地映射和错误状态 |
| 长歌词显示异常 | 遮挡桌面或撑破窗口 | 固定窗口尺寸并单行省略 |
